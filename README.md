# Animated Radial Octagon Menu

A stylish, responsive, and high-performance radial menu built with a focus on CSS animations and clean UI design.

## 🚀 Features
- **Octagonal Geometry:** Precise CSS positioning for 8 distinct action items.
- **Neon Glow Effects:** Interactive hover states with vibrant glow transitions.
- **jQuery Powered:** Smooth toggle logic for opening and closing the menu.

## 🛠 Tech Stack
- **HTML5**
- **CSS3** (Transitions, Keyframes, Flexbox)
- **jQuery** (DOM Manipulation)
